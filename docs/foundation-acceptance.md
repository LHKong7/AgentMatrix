# B0 shared foundation acceptance

**Decision: B0 passes on the macOS arm64 development host.** Recorded September 20, 2026 (Asia/Seoul). The [verification record](probes/2026-09-20-foundation-acceptance.json) combines a strict Electron run with inspected contract assertions and the unchanged production sources covered by the preceding 983-test unit run.

The [plan's B0 gate](cli-agent-plan.md) requires migration, editable unresolved drafts that cannot launch, and agreement between the initial three-engine configuration model, credential API, resolution contract and session API. Its dependencies are A7, A9, A10, A11 and A12. This decision accepts those shared contracts on the measured host. OpenCode B7, Pi C4 and DSH D4 remain open for their own runtime acceptance; B0 does not require an external model call or complete native winning-source attribution.

## Verification changes

`npm run test:foundation` builds the application and runs the existing complete desktop smoke with `--foundation`. The ordinary smoke still tests the unavailable-storage UI when no secure backend exists; the B0 mode instead requires actual OS encryption. Six explicit UI/main draft rejections and replacement-value decryption after a second restart are additional assertions. The fixture records those outcomes separately from general plugin inspection.

The strict desktop check, lint and production build passed. The current `src/`, unit tests, test helpers/fixtures, unit configuration and lockfile match commit `8083c08`, which records 983 passing tests across 61 files. Their assertions were inspected for the requirements above; the unchanged unit suite was not rerun. The new record includes fixture/source hashes and the fresh build hashes. Native CLI execution and model calls are zero in this desktop run.

```sh
AGENT_MATRIX_FOUNDATION_REPORT=/absolute/path/to/foundation.json \
AGENT_MATRIX_FOUNDATION_SCREENSHOT=/absolute/path/to/foundation \
npm run test:foundation
```

The screenshot prefix produces `.en.png` and `.zh-CN.png` files. Screenshots are optional for rerunning the assertions. Run desktop/native suites sequentially and complete the build before launching Electron.

## Gates that remain open

B7/C4/D4 retain their actual endpoint/model/credential acceptance and X3 requirements. Intended external service details are still pending. Native provenance must retain its observed or unknown scope; optional unverified features cannot inherit another route's result. This foundation decision does not enable additional operating systems, package/sign a release, install arbitrary plugins, or complete the overall implementation plan.
