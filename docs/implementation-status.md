The active application reads/writes schema v2 through a single store. Existing v1 files migrate with exact-byte backups; browser preview retains its old v1 key. All nine configuration collections have compatible English/Chinese editors. Native CLI installations used for probes are not automatically registered as user profiles. Configured installation paths are unprobed until runtime verification is connected, and saving a draft does not execute a CLI.

Latest verification: 159 unit tests, two opt-in installed-CLI ACP initialization/cleanup checks, ESLint, TypeScript, production build, and changed-file formatting passed. Real Electron verification covers exact-byte v1 migration, all three engine drafts, shared connections/models, prompt and Skill revisions, directory capture/reimport, pinned/latest bindings, bundles, bilingual diagnostics, deletion cleanup, restart, and OS-encrypted credential creation/replacement/deletion. The native folder chooser is substituted in the smoke test; the actual import IPC, capture service, filesystem, and editors run unchanged. The desktop smoke uses synthetic credentials and does not execute agents or call providers. The session modules are not exposed in that UI yet.
